1先会用：三步
1
用 Chrome 或 Edge 打开这个网页（手机上用自带浏览器也行）。
2
想写字：双击空白处打字。想换工具：电脑上按住右键转一圈松开，手机长按一下会出现转盘，点一下就换好。
3
不用点保存。每改一次自动存，关掉网页再打开还在（同一个浏览器）。
先记住一句：画的内容存在「这台设备的浏览器」里，换设备要自己搬，下面第二块讲怎么搬。
2让手机和电脑是同一份画板二选一
两种办法，用手机就选 A，只用电脑就选 B。两个都做也行，但会各存一份。
A · 手机 / 平板：登录一次，自动同步
1
点下面的 「登录云端账号」，选「账号密码」，填你的邮箱和一个密码。
2
这个邮箱第一次用的话，会自动帮你注册并直接进去，不用等邮件。
3
登录好后，手机和电脑都填同一个邮箱，两边就是同一份画板，改哪边都会自己同步。
同步状态 未登录
手机浏览器没法直接写本地文件夹，所以手机上只走这一条。登录一次就记住，下次打开自动同步。
B · 电脑：存进百度网盘「同步空间」
1
电脑上装 百度网盘客户端，登录你的账号。
2
打开客户端 → 设置 → 同步空间 → 打开开关。它会在这台电脑上建一个文件夹，记住它在哪。
3
回到这里，点 「选择同步空间文件夹」，选中刚才那个文件夹，浏览器问你「允许写入」时点允许。
4
以后每 5 分钟自动写一个 纸面备份.json 进去，网盘客户端负责传上云，你不用管。

?「Supabase」到底是什么？
账号密码登录之后，画板得先存到一个云端的仓库里，另一台设备才取得到同一份。Supabase 就是那个仓库。
它已经帮你连好了——面板下方折叠区里那两行地址和 key，就是仓库的门牌号和钥匙。你不用注册 Supabase、也不用建表，直接跳过就行。
哪天才用得上折叠区？只有你想把画板存进自己另外建的一个仓库时才需要，普通使用一辈子都不用点开。
3换新设备：把画板搬过去
1
新电脑：装网盘客户端并打开同步空间，等它把 纸面备份.json 下载到本地。
2
打开纸面 → 打开本面板 → 选同一个文件夹 → 点 「从备份文件夹恢复」。
3
没有网盘、或者想在手机上看：用 「导出 .json」 把文件发给自己，再到另一台点 「导入 .json」。
4导出：发给别人或打印
1
SVG：文字能选中、能继续改，适合给同事接手编辑。
2
PNG：一张 2 倍清晰的图片，适合发微信、贴进 PPT。
3
文本 .txt：把便签和卡片上的字按顺序列出来，适合存档、搜索。

项目地址
anon key（publishable）
create table if not exists pb_docs (
  user_id uuid primary key references auth.users on delete cascade,
  payload jsonb not null,
  updated_at timestamptz not null default now()
);
alter table pb_docs enable row level security;
create policy "own docs" on pb_docs
  for all using (auth.uid() = user_id)
  with check (auth.uid() = user_id);

登录到「纸面」
验证一次，这台设备会被记住。云端口令登录后，数据会跟着账号在多台设备之间同步。
收不到邮件大多是 Supabase 默认邮件服务的频率限制（免费项目每小时 4 封，且常被 163/QQ 拦截）。想稳定登录请用「账号密码」档。
Supabase 的短信要先在 Authentication → Providers → Phone 里接 Twilio 等短信商；国内号码送达率不稳定，收不到就切「邮箱」那档。
云端账号是可选的：不登录也能用，数据存在本机浏览器，并且每 5 分钟写进你的百度网盘同步文件夹，换设备时从那个文件恢复即可。想要实时多端同步再登录云端。
